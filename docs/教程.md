# 迈凯轮展示台教程

## 启动

```bash
cd /Users/Spire/AI/ChatGpt/fire/McLaren
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:3100 。

画册和管理页需要管理员密码。启动前在环境里设置：

```bash
export MCLAREN_ADMIN_PASSWORD='你的密码'
```

没有这行时，首页仍可看。登录页会提示服务器还没有设置管理员密码。

## 看首页

中间是当前车。右下角可以换 Gulf F1、MCL35M、MP4/6、F1 AMR23。

- 拖动画面环视，滚轮缩放。
- 「点按起步」后按钮变成「点按减速」，镜头改为车尾跟随。
- 左侧章节可跳到车辆、空力、动力、轮胎、科技。
- 右上角依次是：模型展示、背景音乐、沉浸式、深浅色。

## 三种展示效果

点右上角立方体图标，打开「模型展示」。

1. 选「原生」，确认车身是涂装、没有绿线。
2. 选「叠加线框」，涂装还在，车身多一层绿色网格，轮胎仍是黑色实体。
3. 选「纯线框」，整车变成绿色网格。
4. 点色点可以换线框颜色。再点另一辆车，面板标题和车身一起换。
5. 「重置视角」回到这辆车的默认机位。「退出展示」或「返回」回到首页。

## 管理车型

登录后打开 http://127.0.0.1:3100/showcase/pipeline 进入画册，或打开 http://127.0.0.1:3100/showcase/import 进入管理台。

新车型保存在 `public/uploads/mclaren/`，并写入 `showroom.json`。不要把超过 100MB 的原件提交进 Git。
