# 迈凯轮展示台规范

独立站点只负责车型展示。不保留 Alcor 的投资账本、后台入口或指向已删除页面的按钮。

## 页面

| 路径 | 作用 | 谁能用 |
| --- | --- | --- |
| `/` | 展示台首页 | 所有人 |
| `/showcase/pipeline` | 车型画册 | 管理员 |
| `/showcase/import` | 车型管理 | 管理员 |
| `/login` | 管理员登录 | 所有人 |

首页左上角不再放「进入后台」。那个按钮原来指向 `/records`，本站没有这个页面，点击只会 404。

## 首页车型

可见车型以 `public/uploads/mclaren/showroom.json` 为准，再去掉 `hiddenIds`。当前首页是：

- Gulf F1
- MCL35M
- MP4/6
- F1 AMR23

内置 MCL35M 的原件在 `public/mclaren/`。导入车的原件、预览、GPU 副本和封面在 `public/uploads/mclaren/`。隐藏的 MP4/5、MCL39 原件超过 Git 单文件 100MB，不放进仓库，首页也不显示。

## 右上角「模型展示」

三种模式必须分开，不能混成一种：

- **原生**：只显示涂装，不叠线框。
- **叠加线框**：涂装保留，上面再盖一层线框。轮胎仍是实体。
- **纯线框**：整车改成线框，包括轮胎。

线框颜色六选一，默认绿色。切换车型后，机位数字和面板选中态要跟着当前车走。面板可以关，也可以「退出展示」回到首页叙事。

## 加载

先锁定机位并露出地面光环，再显示「正在加载模型」和进度条。进度结束前不要把失败当成已换车。内嵌贴图用 blob 地址读取时，请求不能带 credentials，否则浏览器会拒绝，控制台出现 `Couldn't load texture "blob:..." `。

## 按钮

每个可见按钮都要有结果：切页、切车、切模式、播放、起步、沉浸式或关闭面板。没有目标页面的入口不要留在界面上。
